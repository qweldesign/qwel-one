# QWEL ONE (WordPress Theme)

QWELのオリジナルテーマ開発のスターターキットとして、  
2019年頃から使用し、様々な派生テーマを制作してきた。

いわゆるクラシックテーマであったことから、  
2022年頃からブロック・テーマとして同時開発を進めてきた  
[**QWEL TWO**](https://github.com/qweldesign/qwel-two) に置き換わり、  
2022年末頃、開発終了を迎えた。
